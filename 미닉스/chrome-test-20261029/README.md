# 크롬 도구 수집 테스트 (2026-10-29)

Claude in Chrome 확장으로 사용자의 실제 크롬에서 미닉스 더 플렌더 PRO 상품 페이지를 열어 리뷰와 화면을 모은 테스트 결과.

## 결과
- 보안 확인 화면 없이 열렸다. 9월 12일 Playwright 실행에서 막혔던 것과 다르게 실제 크롬 프로필에서는 통과했다.
- 리뷰 80건을 별점별 20건씩(별점 필터 1~4점, 각 2페이지) 추출했다. 파일은 미닉스크롬1~4.csv. 원본 JSON은 reviews-raw.json.
- 추출 방식은 페이지 안에서 자바스크립트로 리뷰 요소 텍스트를 그대로 복사한 것이라 옮겨 적기 오류가 없다. 별점은 필터로 정해지므로 별 아이콘을 읽을 필요가 없었다.
- 스크린샷은 screenshots/ 아래 상품 요약 1장, 별점 분포 창 1장, 상품 상세 6장.

## 지킨 원칙
- 서버 요청(별점 필터 변경, 페이지 이동) 사이 30초 이상 간격.
- 로그인·장바구니·구매 등 어떤 버튼도 누르지 않음. 상세 "상품정보 더보기"만 펼침.
- 보안 확인 화면이 나오면 즉시 중단하는 검사를 매 단계에 넣었고 한 번도 발동하지 않았다.

## 한계
- 사용자가 자리에 있고 크롬이 열려 있어야 한다. 예약 실행은 안 된다.
- 페이지당 토큰 비용이 든다. 상품 하나 80건에 약 10번의 페이지 요청이 필요했다.
- 리뷰 제목이 없는 글은 제목 칸이 비거나 본문 첫 줄이 들어갈 수 있다.
- 별점 필터 드롭다운은 화면 좌표로 클릭한다. 쿠팡 화면 구조가 바뀌면 좌표를 다시 잡아야 한다.

## 기존 파이프라인 호환 확인
- `python scripts/review_pipeline.py "미닉스/chrome-test-20261029"`로 미닉스크롬_review_analysis.xlsx가 정상 생성됐다(요약·1~4점 시트, 정성 분석 빈 컬럼 3개 포함).
- 주의 1. 별점마다 20건씩 잘라 왔기 때문에 요약 시트의 비율(25%씩)과 리스크 점수(0.5)는 실제 분포(1점 77, 2점 20, 3점 83, 4점 319)를 반영하지 않는다. 실제 분석에 쓰려면 별점별 전체 페이지를 받아야 한다.
- 주의 2. 스크린샷을 screenshots/ 하위 폴더에 두어서 엑셀의 스크린샷 시트가 만들어지지 않았다. 기존 방식처럼 CSV와 같은 폴더에 두면 들어간다.
